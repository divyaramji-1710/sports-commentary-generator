# Sports Commentary Generator

[![Built with askThili](https://ask.thili.ai/api/v1/public/projects/huhdbksy6b/badge.svg)](https://ask.thili.ai/b/huhdbksy6b)

This project provides game developers with a powerful tool to generate dynamic and context-aware sports commentary. By fine-tuning a pre-trained language model with LoRA, it adapts to create engaging snippets for simulated sports events like goal alerts or score changes. The tool demonstrates how LoRA can efficiently customize LLMs for specific domain needs.

## What you are building

The Streamlit interface will allow users to input event descriptions and generate relevant, engaging commentary, demonstrating the model's ability to produce dynamic sports commentary after adapter merging.

## Dataset

The dataset contains 480 synthetic football event/commentary pairs:
360 training, 60 validation, and 60 test examples.

Event types: goal, save, and full-time.
Team names are fictional. Commentary is generated from authored
templates; no real match reports are used.

Generation is reproducible using seed 17 in app/data.py.
Event descriptions do not overlap across splits, but teams and
commentary templates are shared. Evaluation therefore measures
performance on new combinations within this controlled format.

The test split is reserved for final evaluation.

## LoRA training results

The frozen distilgpt2 base was adapted by training 147,456 LoRA
parameters on 360 synthetic event/commentary pairs for six epochs
(270 steps).

Response-only validation loss on 60 examples fell from 3.1500
to 0.0976. The best adapter was saved at step 270.

Example validation output:

Event: Football. Minute 89. Goal for Eagles.
Score after goal: Eagles 3-3 United.

Generated: Eagles score! That makes it Eagles 3-3 United.

Initial inspection of one goal, save, and full-time example found
that all three preserved the event type, teams, and score.
This is a small qualitative check; full evaluation follows later.

## Held-out evaluation

Evaluation used 60 held-out synthetic events with greedy decoding.

| Check | Base model | LoRA-adapted |
| --- | --- | --- |

Full generated outputs are saved in artifacts/evaluation.json.

These results measure new event combinations within that format.
