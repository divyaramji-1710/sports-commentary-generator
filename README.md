# Sports Commentary Generator

[![Built with askThili](https://ask.thili.ai/api/v1/public/projects/huhdbksy6b/badge.svg)](https://ask.thili.ai/b/huhdbksy6b)

This project provides game developers with a powerful tool to generate dynamic and context-aware sports commentary. By fine-tuning a pre-trained language model with LoRA, it adapts to create engaging snippets for simulated sports events like goal alerts or score changes. The tool demonstrates how LoRA can efficiently customize LLMs for specific domain needs.

## What you are building

**Goal.** You will build a tool for game developers that uses a LoRA-adapted language model to generate dynamic and context-aware sports commentary snippets for simulated sports events.

**Done when.** You will have successfully trained a LoRA adapter on a pre-trained LLM using your custom dataset of sports events and commentary pairs. The Streamlit interface will allow users to input event descriptions and generate relevant, engaging commentary, demonstrating the model's ability to produce dynamic sports commentary after adapter merging.

## Run it

You need Python 3.12 and git.

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then choose a model; see the comments inside
streamlit run app/main.py
pytest
```

Your work goes in `app/core.py` (one stub per milestone) and `tests/test_core.py`. The first tests pass already; they
check the plumbing.

## Settings and secrets

Model settings live in `.env`, which is ignored by git. **Never commit `.env` or paste a key into code.** If a key ever
reaches GitHub, treat it as leaked and make a new one.
